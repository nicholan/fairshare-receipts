## Decisions and Constraints

- Money is integer cents with a branded `Cents` type; no floating point in domain arithmetic (ADR-0001).
- Allocation uses largest remainder with deterministic index tie-breaking (ADR-0002).
- Split semantics: even item claims, extras proportional to claimed subtotal, explicit unclaimed bucket (ADR-0003).
- Debt simplification is greedy and deterministic, at most n−1 transfers, explicitly not minimal (ADR-0004).
- Extraction uses one provider-neutral contract plus an arithmetic reconciliation gate; no automatic acceptance (ADR-0005).
- **Currency (ADR-0006):** EUR-only MVP. `SUPPORTED_CURRENCY_CODE = "EUR"`; `currencyCodeSchema` rejects every other code; `tripCreateInputSchema.currency` and `receiptExtractionSchema.currency` are required. Do not add multi-currency or change amount semantics without a new ADR.
- `simplifyAcrossTrips` remains currency-free because only EUR trips can be persisted. It must gain an explicit currency argument before any other currency is introduced.
- The database schema is intentionally identity-agnostic: `trip_members` are opaque participants. **The identity/authorization model is undecided.** Do not add identity columns, auth middleware, or trip/receipt endpoints before the user settles it and an ADR is recorded.
- `.cline/skills/` was intentionally removed from `AGENTS.md`; do not re-add it without a real skill to host.
- `.agent/HANDOFF.md` is committed at the end of every session (repository policy). Keep it free of secrets, tokens, and receipt data.
- OCR/LLM output is candidate data only. User review is required before anything feeds collaborative allocation.

## Open Issues / Assumptions

- **Wrangler is not authenticated.** `wrangler whoami` reports not logged in, so `wrangler d1 create fairshare-db` was not run and `database_id` remains `00000000-0000-0000-0000-000000000000`. Do not create remote resources without authorization.
- **Identity model undecided.** No authentication, authorization, session, or identity code exists. Options discussed but not chosen: (a) anonymous trip membership plus a secret device token, with the join code used only to join; (b) the same plus a nullable `user_id` for later account linking; (c) full accounts (magic link or passkey) from the start; (d) defer and build only the query layer.
- `parseAmountToCents` strips non-EUR markers (`$`, `kr`) without reporting them; extraction must treat such sources as unsupported currency (open in architecture section 10).
- `settlements` member foreign keys use `ON DELETE cascade`, so deleting a trip member would delete their settlement history. No member-deletion flow exists; revisit with the identity/lifecycle decision.
- `worker-configuration.d.ts` is about 620 KB of generated types; regenerate after any binding or config change and keep Biome's exclusion.
- No API/mobile/db test runner. Root `bun test` scans the whole repo and will collide with a Vitest suite in `apps/api`; revisit the root `test` script when one is added.
- `apps/api/tsconfig.json` does not extend `tsconfig.base.json`, and mobile pins TypeScript `~6.0.3` while the root uses `^7.0.2`. Typecheck passes today; align or document deliberately.
- The schema has no receipt-extraction provenance fields (method, provider, model, confidence), matching ADR-0005's deferral.
